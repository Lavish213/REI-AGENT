# Workflow recovery and operational synchronization

Implemented and locally tested: durable five-touch schedules; atomic claim ownership; permanent quarantine of uncertain processing outcomes; no cooldown bypass; tenant-bound inbound email threads and immutable event replays; durable intake before remote application; duplicate-safe PostgreSQL reply application; email pause after replies; explicit suppression on STOP; source snapshot callbacks, follow-ups, offers and email replies; version-bound source callback commands with persistence receipts.

The new email endpoint is a normalized authenticated adapter contract, not a claim that SendGrid sends custom HMAC headers. A trusted receiving adapter must verify transport and sender authentication, reject unauthenticated sender assertions, extract the reply token, and submit only bounded normalized JSON. INBOUND_EMAIL_ADAPTER_SECRET must contain at least 32 characters. Headers are X-Email-Timestamp and X-Email-Signature; signature is HMAC-SHA256(timestamp + '.' + exact raw JSON body). Fields: event_id, thread_token, sender, sender_verified=true, text. Receiving domains/MX and the provider adapter need live account configuration. Official reference: https://www.twilio.com/docs/sendgrid/for-developers/parsing-email/setting-up-the-inbound-parse-webhook . Outgoing lead emails use a persisted random reply token when INBOUND_EMAIL_DOMAIN is set. Unbound emails do not acquire guessed lead identity.

Apply 20261016_workflow_recovery.sql after the reviewed prior migrations. Dashboard source command transport uses REI_COMMAND_URL and SOURCE_COMMAND_SECRET; Sophia must use the same SOURCE_COMMAND_SECRET. Callback commands are role-checked in the dashboard, bound to tenant/lead/property and exact source updated_at, durably queued, and applied once by the source SQL function. A queued command is not a confirmed callback. Source data revisions and delivery receipts stay distinct. Stale versions and changed destinations require review. The source never automatically converts arbitrary dashboard edits into price authority.

Dashboard calendar/deals/follow-ups now display actual source records alongside existing dashboard records. They preserve walkthrough/callback/follow-up distinctions and label stale snapshots. Callback write-back is implemented; full arbitrary bidirectional changes to offers, disposition, booking cancellation and source candidates are not implemented by this patch.

WORKFLOW_JOURNAL_PATH must be an absolute private persistent path (default /data/sophia/workflows.sqlite3). Pending work survives restarts; stale processing claims are quarantined after ten minutes instead of redialed. The journal is SQLite: actual volume durability and replica topology require deployment acceptance. WORKFLOW_REVIEW_OWNER_ID must designate a real operator. Health and review queue endpoints expose job state and uncertain outcomes. Health does not prove a mounted persistent volume.

Externally blocked: production account/DNS/adapter setup; real audio/provider tests; current San Joaquin held-out sold/condition/repair evidence; actual shared database baseline and data-preserving upgrade/rollback; verified volume/replica behavior. County assessed values are not sale-price or ARV truth. Official county source: https://www.sjgov.org/department/assessor/property-information/homeowners . Do not grade current California valuation accuracy using tax assessments or synthetic comp invariants.
